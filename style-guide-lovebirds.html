02 · Typography

Four families, deliberate roles

Cormorant Garamond untuk semua display & heading (sering italic). DM Sans untuk body & UI. Great Vibes sebagai aksen script (monogram, nama). Kameron sebagai serif lembut alternatif. Import di fonts.css.

--font-display
Aa
Cormorant Garamond
High-contrast display serif. Italic dipakai berat untuk judul section. Fallback: Times New Roman, serif.
--font-body
Aa
DM Sans
Geometric grotesque. Body, paragraf, eyebrow, kontrol form. Fallback: Helvetica Neue, Arial, sans-serif.
--font-script
Aa
Great Vibes
Script formal. Monogram, nama pengantin, sentuhan romantis. Fallback: Alex Brush, cursive.
--font-serif-soft
Aa
Kameron
Slab-ish serif lembut. Alternatif tenang untuk badan teks panjang. Fallback: Cormorant Garamond, serif.

05 · How to use

Consuming the system

Di CSS

/* Pakai token apa pun lewat CSS var */
.my-card {
  background: var(--glass-bg);
  color: var(--fg);
  border: 1px solid var(--glass-border);
  border-radius: var(--border-radius-card);
  box-shadow: var(--shadow-card);
  transition: transform .35s var(--ease-out);
}
.my-card__title {
  font-family: var(--font-display);
  color: var(--accent);
}

Terapkan tema per-section

// defaultConfig.js — set field theme:
{
  id: 'hero',
  type: 'hero',
  theme: 'darkLuxury', // themes.js
  props: { /* … */ },
}

// themes.js — resolve ke object CSS var:
import { resolveTheme } from './config/themes';
const vars = resolveTheme('darkLuxury');
// → di-spread ke style section wrapper
